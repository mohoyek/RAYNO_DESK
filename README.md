# راینو دسک (RAYNO_DESK)

**راینو دسک** یک نسخهٔ سفارشی‌سازی‌شده از نرم‌افزار متن‌باز [RustDesk](https://rustdesk.com) است که به‌طور اختصاصی برای **گروه پشتیبانی نرم‌افزار مالی راینو** طراحی و کامپایل شده است. این نسخه در قالب یک **کلاینت ۳۲ بیتی ویندوز** ارائه می‌شود و تنها امکان مشاهده و ارائهٔ **شناسهٔ دستگاه (ID)** به تیم پشتیبانی را برای کاربر فراهم می‌کند. سایر تنظیمات و قابلیت‌های پیشرفتهٔ RustDesk در این نسخه غیرفعال یا پنهان شده‌اند تا فرآیند پشتیبانی از راه دور برای کاربران نهایی ساده و ایمن باشد.

> تغییرات و سفارشی‌سازی این پروژه با استفاده از ابزار **KiloCode** در محیط **Visual Studio Code (VS Code)** انجام شده است.

---

## ویژگی‌های کلیدی

- **کلاینت ۳۲ بیتی ویندوز**: سازگار با سیستم‌های ویندوزی ۳۲ بیتی (x86) و همچنین قابل اجرا روی ویندوزهای ۶۴ بیتی.
- **نمایش فقط شناسه**: کاربر تنها می‌تواند شناسهٔ (ID) دستگاه خود را مشاهده و به تیم پشتیبانی ارائه دهد.
- **غیرفعال‌سازی تنظیمات پیشرفته**: دسترسی به تنظیمات سرور ID، رله، کلید امنیتی و سایر پیکربندی‌های پیشرفته مسدود شده است.
- **رابط کاربری ساده**: واسط کاربری به‌گونه‌ای تغییر یافته که تنها اطلاعات ضروری برای پشتیبانی نمایش داده شود.
- **مبتنی بر RustDesk**: از هستهٔ قدرتمند و امن RustDesk بهره می‌برد.

## راهنمای نصب و استفاده

### ۱. دریافت فایل اجرایی

فایل اجرایی کلاینت ۳۲ بیتی را می‌توانید از بخش [Releases](https://github.com/mohoyek/RAYNO_DESK/releases) مخزن دریافت کنید. فایل خروجی معمولاً با نامی مشابه `RAYNO_DESK-x86.exe` منتشر می‌شود.

### ۲. اجرای برنامه

پس از دانلود، فایل اجرایی را اجرا کنید. نیازی به نصب نیست و برنامه به‌صورت Portable اجرا می‌شود.

### ۳. ارائهٔ شناسه به پشتیبانی

پس از اجرا، صفحهٔ اصلی برنامه تنها **شناسهٔ دستگاه (ID)** شما را نمایش می‌دهد. این شناسه را کپی کرده و در اختیار تیم پشتیبانی راینو قرار دهید. تیم پشتیبانی با استفاده از این شناسه می‌تواند به‌صورت از راه دور به سیستم شما متصل شود و مشکل را بررسی کند.

> **نکته امنیتی:** هرگز شناسهٔ خود را در اختیار افراد ناشناس قرار ندهید. تنها شناسه را به تیم پشتیبانی رسمی راینو ارائه کنید.

## تغییرات و توسعه با KiloCode

تمام تغییرات این پروژه نسبت به نسخهٔ اصلی RustDesk با استفاده از **KiloCode** و در محیط **VS Code** انجام شده است. این تغییرات شامل موارد زیر است:

- **سفارشی‌سازی رابط کاربری** برای نمایش تنها شناسهٔ دستگاه و حذف گزینه‌های غیرضروری.
- **محدودسازی دسترسی کاربر** به تنظیمات سرور، رله و سایر پیکربندی‌های پیشرفته.
- **کامپایل نسخهٔ ۳۲ بیتی ویندوز** متناسب با نیاز کاربران نهایی.
- **ساده‌سازی فرآیند پشتیبانی** به‌گونه‌ای که کاربر فقط شناسه را به تیم پشتیبانی ارائه دهد.

> این پروژه در محیط VS Code و با کمک ابزار KiloCode توسعه یافته و تغییرات آن مستند شده است.

## محدودیت‌ها

- این نسخه **فقط برای ویندوز** ساخته شده است و روی لینوکس یا مک اجرا نمی‌شود.
- **امکان تغییر سرور ID یا رله** از داخل کلاینت وجود ندارد؛ این تنظیمات هنگام کامپایل به‌صورت ثابت در برنامه قرار می‌گیرند.
- **قابلیت‌های پیشرفتهٔ RustDesk** مانند انتقال فایل، کلیپ‌بورد اشتراکی و ترمینال از رابط کاربری حذف شده‌اند تا فقط برای اهداف پشتیبانی ساده استفاده شود.
